# Security

Kryptos is a password manager: vulnerabilities should be reported **privately**, never in a public issue.

## How to report

Use GitHub's private reporting: the **Security → Report a vulnerability** tab of this repository.

Please include, if possible:
- version or commit and platform (macOS, Android, browser extension…);
- steps to reproduce the issue;
- the impact you'd expect (e.g. "another local app can read passwords").

You'll get a response within 7 days. Once a fix is published, you'll be credited in the release notes if
you'd like.

## Scope

In scope, for example:
- decrypting the vault or extracting data from it without the master password;
- obtaining credentials through the browser bridge, the extension or the Android autofill service without
  user action, or for a site other than the one it's saved for;
- any network traffic generated by the app;
- sensitive data leaking into logs, temporary files, the clipboard or backups.

Out of scope: attacks that require full control of the system (root or jailbreak), or malware already
running that logs keystrokes. The full threat model is in
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

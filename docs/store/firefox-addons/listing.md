## Italiano

**Nome:** Kryptos

**Riepilogo:** Compila login e 2FA dal vault Kryptos sul tuo computer. Nessun server, nessun account. Richiede l'app Kryptos. Una conferma per ogni compilazione.

**Descrizione**

Kryptos compila username, password e codici 2FA dal vault che tieni sul tuo computer. L'estensione funziona insieme all'app Kryptos per computer, che va installata a parte: da sola non contiene password.

COSA FA
• Tendina sotto i campi di accesso con i login del sito
• Popup con i login del sito, ricerca nel vault e generatore di password
• Una conferma per ogni compilazione: Touch ID, password del Mac o master password
• Salvataggio di nuovi login e password cambiate
• Lettura del QR della 2FA sulla pagina, che Kryptos aggiunge alla voce che scegli
• Avviso quando una pagina imita un sito che hai salvato
• Tasto destro su un campo: compila o genera una password

COME TRATTA I TUOI DATI
L'estensione parla solo con l'app sul tuo computer, tramite Native Messaging del browser. Non usa server, non ha account e non contiene statistiche o tracciamento. Sulle pagine gira un piccolo script che nota il clic su un campo di accesso e apre la tendina: non legge quello che scrivi e puoi spegnerlo dal popup.

Kryptos è alla versione 0.1, sperimentale: il codice non ha avuto una revisione di sicurezza indipendente. Non usarlo come unica copia di password importanti.

Codice sorgente (GPL-3.0): https://github.com/SimoneVella/Kryptos

## English

**Name:** Kryptos

**Summary:** Fills logins and 2FA codes from the Kryptos vault on your computer. No servers, no accounts. Requires the Kryptos app. One confirmation for every fill.

**Description**

Kryptos fills usernames, passwords and 2FA codes from the vault on your own computer. The extension works together with the Kryptos desktop app, which you install separately: on its own it holds no passwords.

WHAT IT DOES
• A list under login fields with the site's logins
• A popup with the site's logins, vault search and a password generator
• One confirmation for every fill: Touch ID, Mac password or master password
• Saves new logins and changed passwords
• Reads a 2FA QR code on the page, and Kryptos adds it to the entry you choose
• Warns you when a page imitates a site you saved
• Right-click a field to fill or generate a password

HOW IT TREATS YOUR DATA
The extension talks only to the app on your computer, through the browser's Native Messaging. It uses no servers, has no account, and contains no analytics or tracking. On pages, a small script notices a click on a login field and opens the list: it doesn't read what you type, and you can turn it off from the popup.

Kryptos is at version 0.1 and experimental: the code has not had an independent security review. Don't use it as the only copy of important passwords.

Source code (GPL-3.0): https://github.com/SimoneVella/Kryptos
